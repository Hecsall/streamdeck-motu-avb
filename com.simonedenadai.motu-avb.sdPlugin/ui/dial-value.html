API Connection

For compatible MOTU AVB devices, the API URL is the URL of your MOTU device web interface, adding a "/datastore" at the end.
If the API URL is not valid, the Endpoint selector will not populate.

Rotation

When the dial is rotated, the plugin will read the current value of the Rotation Endpoint and add or subtract the Step for each tick.

Rotating clockwise increases the value, counter-clockwise decreases it.

The step is in dB — the plugin handles the conversion to the amplitude ratio value expected by the API.

Endpoint example: mix/chan/0/matrix/fader

Dial Press

When the dial is pressed down, the plugin will set the Press Endpoint to the specified Press Value.

Leave all fields empty if you don't need the press action.

Endpoint example: mix/chan/0/matrix/mute
